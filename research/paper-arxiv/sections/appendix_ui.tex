\section{Compliance Cockpit}
\label{app:ui}

The Cockpit is the operator's view of everything in \S\ref{sec:arch}. The
views below are unretouched screenshots taken against a gateway while
the compatibility matrix of Appendix~\ref{app:compat} was running, so
every number on them comes from the calls in Table~\ref{tab:compat}. The
interface uses one typeface and no colour except where it carries a
decision: red for a block, amber for a hold, black for the primary
action.
