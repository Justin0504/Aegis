\section{Compliance Cockpit}
\label{app:ui}

The Cockpit is the operator's view of everything in \S\ref{sec:arch}. The
views below are unretouched screenshots of the Cockpit attached to the
gateway database that the compatibility matrix of
Appendix~\ref{app:compat} produced; the agents, traces and chains on
them are the matrix's, and the blocks and holds visible on the overview
and approval views were driven into the same gateway with the matrix's
S2 and S3 payloads immediately before the capture, so that the queue
was not empty. The interface uses one typeface and no colour except
where it carries a decision: red for a block, amber for a hold, black
for the primary action. The overview is Figure~\ref{fig:dashboard}.
