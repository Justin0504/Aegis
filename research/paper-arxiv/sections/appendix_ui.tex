\section{Compliance Cockpit}
\label{app:ui}

The Cockpit is the operator's view of everything in \S\ref{sec:arch}. The
views below are unretouched screenshots from two sources, neither seeded
by hand. The overview, approvals, activity and Security~360 views show
seven real AgentDojo runs of the qwen3:8b agent
(\S\ref{sec:agentdojo}) replayed through the shipping SDK and gateway:
every user turn and tool return is reported as context, every call is
checked afresh by the current gateway, and every trace enters the hash
chain as a deployed agent's would
(\texttt{research/compat/shoot\_replay.sh}); the holds of the last three
runs are left open so the queue shows them with their evidence. The
remaining views use a copy of the gateway database that the
compatibility matrix of Appendix~\ref{app:compat} produced: the agents,
traces, holds, blocks and chains on them are the matrix's. The capture is scripted
(\texttt{research/compat/shoot\_cockpit.sh}): it copies the database,
starts the shipping gateway and Cockpit on it, runs one pre-deployment
scan of the demonstration agent and one alignment audit so that those
two views show a result, and photographs every view. The alignment
auditor ran on a local model (qwen3:8b through Ollama, the model of
\S\ref{sec:agentdojo}), the deployment the fallback of
\S\ref{sec:fallback} describes. The interface
uses one typeface and no colour except where it carries a decision: red
for a block, amber for a hold, black for the primary action. The
overview is Figure~\ref{fig:dashboard}.

\subsection{The demonstration, as photographed}
\label{app:demo-shots}

Figure~\ref{fig:demo} crops these. They are the live demonstration agent
of \S\ref{sec:demo} (Claude Haiku 4.5, the two-line integration shown
there) driven exactly as an attendee drives it, by typing the scenario's
prompt into its chat page
(\texttt{research/compat/shoot\_demo\_flow.sh}), and the Cockpit beside
it. Nothing in a transcript is edited; the model does not emit the S2
call on every turn, and a turn that produced no tool call is reset and
retried.
